# tourism-gravity-brazil

Research compendium for the working paper *Distance, Connectivity, and Price Competitiveness: A Gravity-Based Analysis of International Tourism Demand for Brazil* (Valber Gregory Barbosa Costa Bezerra Santos, UFAL / TJAL).

The repository holds the R pipeline that builds a monthly origin-country panel of international tourist arrivals to Brazil (2000–2025), merges it with distance, air-connectivity and relative-price indicators, and estimates gravity models by PPML with origin and month fixed effects, together with robustness specifications and leave-one-out diagnostics by origin. The question addressed is the relative role of distance, air connectivity and price competitiveness in international tourism demand for Brazil.

## Data and sources

All sources are public. Raw files are not versioned (`data/raw/**` in `.gitignore`); the pipeline downloads them. `data/raw/README.md` documents each file, its retrieval date and the script that fetches it.

| Source | Content | Period | Access |
|---|---|---|---|
| Ministério do Turismo / Embratur, *Chegada de turistas internacionais* (dados.turismo.gov.br, CKAN package `chegada-de-turistas-internacionais`) | arrivals by origin country, access mode and month | 2000–2025 | `R/01_download_mtur.R` |
| ANAC, *Dados Estatísticos do Transporte Aéreo* (gov.br/anac) | flights, seats, passengers, ASK/RPK and direct-service indicator by country-month | 2000-01 to 2025-12 | R package `flightsbr`; `scripts/05d_baixar_anac_completo.R`, consolidated by `R/05_prepare_connectivity.R` |
| CEPII GeoDist | bilateral distances (`distw`, `distcap`, `dist`), contiguity, common language, colonial link | — | R package `cepiigeodist`; `R/04_prepare_geodist.R` |
| World Bank WDI | GDP per capita, population, CPI, exchange rate, GDP and household price levels | annual | R package `WDI`; `R/03_download_macro.R` |

Visa regimes (`data/raw/visa/`) and the multi-destination panel for the structural extension (`data/raw/structural/`) are placeholders with header only and are switched off in `config.yml` (`use_visa: false`, `use_structural_extension: false`).

## Repository structure

```
_targets.R              pipeline definition ({targets})
run_pipeline.R          runs targets::tar_make()
config.yml              period, paths, estimation options and sample contract
renv.lock               locked package versions (R 4.4.2)
R/                      pipeline functions, numbered by stage (00 setup … 13)
scripts/                step-by-step scripts with logs (download, audit, estimation, export)
data/
  raw/                  external sources (not versioned; README documents provenance)
  interim/              intermediate products (not versioned; README lists them)
  processed/            versioned panels and the frozen estimation sample (.parquet)
output/
  tables/               model tables and descriptive statistics (.csv / .html)
  figures/              figures (.png)
  audit/                sample contract, coverage, download and model audits (.csv)
logs/                   execution and audit reports
notes/                  numbers used in the text, each with its source file and column
GUIA_EXECUCAO_ECONOMETRIA.md, NOTA_*.md, PLANO_*.md, LEIA-ME_*.txt   working notes (pt-BR)
```

Versioned data products in `data/processed/`:

| File | Generated by | Target |
|---|---|---|
| `tourism_panel_monthly.parquet` | `build_analysis_panels()` in `R/07_build_panel.R` | `panels` |
| `tourism_panel_access_monthly.parquet` | same | `panels` |
| `econometric_sample_gdp_pli_distw.parquet` | `write_frozen_econometric_sample()` in `R/09_models.R` | `sample_freeze_files` |

Model specifications (formula, estimator, sample) are listed in `output/tables/model_specifications.csv`. The estimation sample is fixed by a contract in `config.yml` (`expected_main_rows`, `expected_main_origins`); the pipeline stops if the sample changes.

## How to reproduce

Requirements: R 4.4, internet access on the first run. Open `tourism-gravity.Rproj` (the `.Rprofile` activates `renv`) or run from the project root.

```r
renv::restore()                              # locked dependencies
source("scripts/00_diagnostico_inicial.R")   # environment check
source("scripts/05d_baixar_anac_completo.R") # ANAC connectivity (long; run as a Background Job)
source("scripts/05e_auditar_anac_completo.R")#   then its audit — outside {targets}
targets::tar_make()                          # MTur, CEPII, WDI, panel, models, tables, figures
targets::tar_outdated()                      # should return character(0)
```

`Rscript run_pipeline.R` is equivalent to `targets::tar_make()`. Stage-by-stage instructions (in Portuguese) are in `GUIA_EXECUCAO_ECONOMETRIA.md` and `data/raw/README.md`. No credentials or environment variables are required.
